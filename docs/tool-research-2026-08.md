# Tool expansion research — August 2026

## Signals used

- [Execute.Online](https://execute.online/) and [DevToolGrid](https://devtoolgrid.com/) confirm the durable developer-tool core: JSON, Base64, URL, JWT, regex, CSV, timestamps, UUID, hashes, SQL, XML, QR, HTTP and MIME helpers.
- [ToolDock](https://tooldock.org/) shows demand expanding into API, network, security, generators and CSS/design workflows, with privacy and smart discovery as differentiators.
- [BrowserUtils](https://www.browserutils.dev/) validates long-tail encoding and inspection workflows such as Base32, binary/text, user-agent, subnet and SAML inspection.
- [Calculator.net](https://www.calculator.net/financial-calculator.html) and [Omni Calculator](https://www.omnicalculator.com/finance) validate percentage, CAGR, margin/markup, VAT, loan and business calculators as stable search categories.
- Public builder feedback repeatedly asks for formula transparency, category filters and narrow calculators that explain their assumptions. A 2026 [calculator-site feedback thread](https://www.reddit.com/r/webdev/comments/1q92axh/i_built_a_website_of_200_free_calculators_would/) specifically calls out formulas and clean category discovery.
- A recent [freelance rate calculator discussion](https://www.reddit.com/r/SideProject/comments/1rdzs8p/i_built_a_freelance_rate_calculator_with_5501/) validates demand for rates that include expenses, non-billable time and platform fees instead of a generic salary conversion.

## Selection framework

Tools were included only when they met all of these constraints:

1. The complete operation can run safely in front-end JavaScript.
2. The result is deterministic or clearly labelled as an estimate.
3. The page can target a specific task-oriented query rather than a vague category.
4. The workflow is useful without an account, server upload or fabricated live-network result.

## Expansion shipped

The catalog grew from 37 to 60 tools. The 23 additions cover:

- Data and API: JSON to TypeScript, JSONPath, JSONL validation, SQL, XML and query strings.
- Encoding: number bases, binary/text and Base32.
- Content and inspection: Lorem Ipsum, Markdown, user-agent, HTTP status and MIME lookup.
- Network and performance: IPv4 subnet and download time.
- AI/privacy: transparent LLM token estimation and PII/secret redaction.
- Business calculations: percentage change, CAGR, margin/markup, VAT/sales tax and sustainable freelance rate.

## Next candidates

Do not add these until the current pages have search and usage data: SAML decoder, OpenAPI-to-tool schema, CSP builder, JSON Schema validator, QR code generator, image metadata inspector, savings-goal calculator and marketplace fee calculators. Their priority should be based on Search Console impressions, internal searches with no results, and anonymized tool-open counts.
